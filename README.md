# Mandarin Quest · Lantern Islands

[Play the public game](https://chines-game.github.io/mandarin-quest/)

Level Zero and Lessons 1–7 are open from the start. Jump directly to [Lesson 4](https://chines-game.github.io/mandarin-quest/#lesson-4), [Lesson 6](https://chines-game.github.io/mandarin-quest/#lesson-6), or [Lesson 7](https://chines-game.github.io/mandarin-quest/#lesson-7).

Each lesson includes source-based vocabulary, pronunciation, grammar, conversations, worksheet exercises, a checkpoint, and source coverage. Chinese connects to Pinyin, English and included audio. Exercises use answer buttons with explanations; long sets are divided into short rounds. Lesson 6 covers shopping and prices; Lesson 7 covers campus places and directions.

The game includes 454 vocabulary entries, 1,443 audio clips and 268 characters with stroke-order animation, guided tracing and recall. Ten mock exam papers remain scoped to Lessons 1–5; new Lesson 6–7 exercises are inside their lesson rooms.

Open the link in Safari on iPhone. Allow the initial audio files to load. Progress is stored in the browser at this address; use My progress → Export progress for a backup before changing browsers or devices. Existing progress is preserved. Hosted reopening without a connection is not guaranteed; a separate standalone HTML build contains all assets for offline study.

Source exercises are adapted to multiple-choice practice, with original versus added material identified in each lesson. Speaking and writing require separate practice; checkpoint stars measure performance on answer choices. Audio combines supplied recordings with synthesized Mandarin. Software and stroke-data license notices are included inside My progress → Sources and course coverage.
